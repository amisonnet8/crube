		mtqg-usage.md	mtqg でメモ・todo・質問・不具合・決まり事を記録する方法
		naming.md	名前：製品名・用語・コマンド
		qsoku-usage.md	ビルド・テスト・lint の qsoku の名前と呼び方

internal/	crube のパッケージ：コアと、その上の CLI
	cli/	コマンドライン：引数を解析し、core を呼び、JSON かテキストで出す
		args.go	オプションの解析（引数の前後どちらに書いてもよい）
		cli.go	コマンド・ヘルプ・版・終了コード・エラーの行
		text.go	テキストの出力：桁揃え、端末幅での切り詰め、status の表
		*_test.go	同名ファイルのテスト
	core/	CLI と MCP サーバーが呼ぶ操作
		core.go	プロジェクトを開く、言語の structure ファイルを読む、ignore ファイルを読む
		edit.go	set・rm・mv
		init.go	init
		read.go	ls・tree・show と、find・status の配線
		*_test.go	同名ファイルのテスト
	ignore/	.crube/ignore：.gitignore と同じ規則と、init が書く既定のファイル
		ignore.go	除外の規則の解析と照合
		*_test.go	テスト（期待値は git check-ignore で求めた）
	lang/	CRUBE_LANG から使う structure ファイルを選ぶ
		lang.go	言語タグとファイル名（structure_<タグ>.txt）
		*_test.go	同名ファイルのテスト
	match/	実在のパスとエントリの照合（名前の完全一致が先、次にパターンを書いた順）
		match.go	Child・Walk・Find
		*_test.go	同名ファイルのテスト
	project/	.crube/ の探索と、そこへ書き込む唯一のコード（書き込みガード）
		project.go	FindRoot と、.crube/ の外やシンボリックリンク経由を拒む書き込み
		*_test.go	同名ファイルのテスト
	search/	find：エントリのパス・desc・detail の検索（インデックスなし）
		search.go	大文字・小文字を区別しない検索。語はすべて含むものだけに当たる
		*_test.go	同名ファイルのテスト
	status/	status：プロジェクトを走査して structure ファイルと突き合わせる（読むだけ）
		status.go	未説明のパス、孤立エントリ、上限超え、充足度
		*_test.go	同名ファイルのテスト
	structure/	structure ファイル：読み込み、正規形での書き出し、desc と detail の上限
		limits.go	desc（256 桁）と detail（4096 桁）の上限と、書けない名前
		structure.go	タブで字下げしたツリーの Parse と Format
		*_test.go	同名ファイルのテスト
	textwidth/	表示幅：全角 2、結合文字 0、ほかは 1
		textwidth.go	1文字と文字列の表示幅
		*_test.go	テスト（期待値は Python の unicodedata で求めた）
